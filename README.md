# BO3 Sound Suite

Application Windows pour le workflow audio des Black Ops III Mod Tools : conversion des sons en WAV BO3 (48 kHz / PCM 16 bits), création des sound aliases CSV et ajout dans les fichiers SZC.

## Télécharger

Téléchargez la dernière version depuis la section **Releases** du dépôt. Extrayez l’archive Windows 64 bits et lancez `BO3 Sound Suite.exe`. Aucune installation de .NET n’est nécessaire.

## Version 1.1.13

Les sons convertis sont enregistrés par défaut dans le même dossier que leur fichier d’origine, qu’ils soient ajoutés par glisser-déposer ou avec le sélecteur de fichiers. Le chemin de sortie reste modifiable dans l’application.

Le projet Visual Studio et le code source sont fournis avec la release.
